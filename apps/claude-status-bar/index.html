Claude Status Bar

How much of your Claude Code 5-hour and weekly limits is gone, and how long until they reset — at a glance, without opening anything.

Install View on GitHub

The number you actually want is how much is left.

Both rate limits at once

The 5-hour window and the weekly one, each with its own meter, percentage and countdown. Colour runs green → amber → orange → red by configurable bands, and the number sits beside the meter — colour is never the only thing carrying the reading.

Updates the moment a session writes

A file watch, not a poll. Rate limits only exist inside a running Claude Code session, so a line is spliced into your statusline.sh (or set as Claude's statusLine on Windows). The reading lands in ~/.claude/statusbar-state.json, and the panel redraws. Nothing about your usage leaves the machine.

Install

Linux, with uv and Python 3.9+:

git clone https://github.com/mkalmousli/ClaudeStatusBar.git
cd ClaudeStatusBar
make install

Windows and macOS (or Linux without make):

uv sync
uv run claude-statusbar --install

The installer wires up capture, then sets up whichever integration fits the machine. --uninstall reverses all of it. Full notes, including the compiled Xfce panel plugin, are in the README.

Where it appears

On Xfce you get a real xfce4-panel plugin (compiled C) — Add New Items… → Claude Status Bar. KDE, Cinnamon, MATE and Budgie get a StatusNotifier tray icon; GNOME the same, with the AppIndicator extension. Windows gets a notification-area icon and macOS a menu-bar item.

The Xfce plugin is a compiled GTK module because the panel loads plugins as shared libraries; everything else is Qt. Both draw the same SVG, so the panel item and the tray icon are the same picture.

Everything else

Honest about staleness

Liveness comes from your newest session log, not the state file — it says updated 16m ago while a turn runs, and only warns when nothing is open.

Several sessions at once

Each session writes its own snapshot; the highest reading in the current window is the freshest, and that's what's shown. The Sessions tab shows it happening.

Settings apply live

No Save button. Only values you change are written, so the rest keep following the defaults across upgrades.

Offline by default

The one network request is an optional once-a-day check for a new release, and it switches off in Settings.
